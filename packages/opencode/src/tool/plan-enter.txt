Use this tool when you have completed a task in build mode and are ready to return to plan mode.

This tool requires you to provide a comprehensive markdown walkthrough detailing:
1. The changes you have made.
2. The testing you have performed.
3. How you validated that your work is correct.

Call this tool:
- ONLY after you have completed the assigned build task and validated your changes.

Do NOT call this tool:
- If you have not yet completed the task.
- If you have not tested and validated your changes.
